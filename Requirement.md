# Infrastructure Capacity Planner

## Background

Infrastructure engineer sering mengalami kesulitan memperkirakan kebutuhan kapasitas storage, backup, dan biaya infrastruktur dalam 1 sampai 3 tahun ke depan.

Perhitungan biasanya dilakukan secara manual menggunakan spreadsheet yang berbeda-beda.

Project ini bertujuan membantu proses capacity planning secara cepat dan konsisten.

---

## Target User

- Infrastructure Engineer
- System Administrator
- IT Manager
- Data Center Engineer

---

## Problem Statement

Bagaimana cara menghitung kebutuhan kapasitas storage dan biaya infrastruktur secara cepat berdasarkan pertumbuhan data aktual?

---

## Input

- Current Storage Capacity
- Current Data Usage
- Monthly Growth
- Retention Period
- Backup Multiplier
- Rack Cost
- Colocation Cost

---

## Output

- Forecast 6 bulan
- Forecast 1 tahun
- Forecast 3 tahun
- Estimated Storage Requirement
- Estimated Cost

---

## MVP Features

- Storage Growth Calculator
- Backup Growth Calculator
- Capacity Forecast
- Cost Forecast
